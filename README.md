# Check Before You Leave
Student prototype (React + Vite). Data is stored in your browser's LocalStorage. No API keys or backend.

    npm install
    npm run dev

Open the local address Vite prints (usually http://localhost:5173).

Files: src/store.js (data, points, streaks, badges) · src/pages.jsx (all six pages) · src/App.jsx (navigation) · src/styles.css (design system).
