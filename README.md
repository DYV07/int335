# 🌿 Check Before You Leave!

> Small actions. Smarter energy. A better campus.

**Check Before You Leave** is a sustainability-focused web application designed to encourage students to reduce unnecessary electricity wastage in university classrooms and shared campus spaces. It promotes responsible energy usage through room exit checklists, energy-awareness reminders, eco-points, activity tracking, and electrical issue reporting.

---

## 📌 Problem Statement

Lights, fans, projectors, and other electrical equipment are often left running in empty classrooms and shared spaces. Students may forget to switch them off, while responsibility for checking equipment may be unclear.

This results in unnecessary electricity consumption and energy wastage.

## 💡 Our Solution

We created **Check Before You Leave!**, a digital energy-awareness platform that encourages students to perform a quick room check before leaving.

The application promotes simple habits that can contribute to a more energy-conscious campus environment.

---

## ✨ Features

- ✅ **Room Exit Checklist** — Check lights, fans, projectors, and other equipment before leaving.
- 📊 **Energy Dashboard** — View checklist activity and energy-awareness progress.
- 🌱 **Eco Rewards** — Earn eco-points and unlock achievements for completed checks.
- 🔔 **Energy Reminders** — Encourage responsible electricity usage.
- 🚨 **Report an Issue** — Report faulty switches or electrical equipment.
- 📈 **Activity Tracking** — Track completed room checks and personal progress.
- 💾 **Local Data Persistence** — Save application activity using browser LocalStorage.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/check-before-you-leave.git
```

### 2. Navigate to the project directory

```bash
cd check-before-you-leave
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the application

```bash
npm run dev
```

### 5. Open in your browser

Open the local URL provided by Vite, usually:


## 🌍 Sustainability Impact

The application is designed to encourage energy-conscious behaviour and reduce unnecessary electricity usage.

It does not directly control electrical devices or measure real electricity consumption. Its impact depends on user participation and the adoption of energy-saving habits.
